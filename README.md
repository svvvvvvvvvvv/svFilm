# svFilm

数码仿胶片管线（重写版）。**代码与 `auto_pipe` 完全独立，只沿用原理，不共用任何一行。**

## 分层契约（改任何一层前先看这张表）

| 层 | 文件 | 输入 → 输出 | 职责 | 铁律 |
|---|---|---|---|---|
| L0 | `analyze.py` | lin/disp → dict | 只读分析 | **判据只用分位，绝不用均值** |
| L1 | `tone.py` | lin → lin | 影调修正 | **靶是绝对靶**；曲线只作用在亮度上；可解析求中灰；**中灰判据只有一把尺子 = L\***（`TGT_MID_L` 58.0 / 过亮护栏 `GUARD_MID_L` 87.0 = 灰阶 218，**都不是中灰 140**）；**白点分两条路**：过曝 → 只设上限 `WHITE_CEIL`（245），兜底提亮 → 守 `TGT_WHITE`（220） |
| ┃ | `denoise.py` | disp → disp | **降噪** | **只在暗部×平坦区下手**；近似零均值（分位不漂）；不打平边缘 |
| L2 | `style.py` | disp → disp | 胶片风格、外部 .cube、**胶片影调曲线** | **不许把 L1 定下的中灰改回去**（`lock_ref` 保证）—— ⚠ **影调曲线例外**：它是**刻意**改影调，所以它的中灰抬升不受锁管辖（锁的参照 `tone_ref()` 会一起过曲线，`lock_ev` 恰好≈0） |
| ┃ | `spatial.py` | disp → disp | **颗粒 / 黑柔 Bloom / Halation** | 邻域运算，**塞不进 LUT**，必须单独一层；**顺序 = bloom → halation → grain**（镜头先于乳剂，见下）；**颗粒两端（暗/亮）精确为 0**；**Halation 分通道半径（R 最远）** |
| L3 | `local.py` | disp → disp | 肤色等局部 | 只改色度，不改明度；**肤色两手：①保护（还回被风格收掉的色度）②正向达标（只向上补到大师脸区档 `SKIN_FLOOR_*`，逐像素设上限，过亮脸按门收力）** |
| L4 | `guard.py` | disp → disp | 护栏 | **只做"不许超过"，永不做"必须等于"** |
| 入口 | `io.py` | 文件 → lin/disp | 解码 + IDT + **曝光零点 + 固定基准成形** | **全工程唯一允许出现"机型"的地方**（`cameras.py` 是数据表）；**零点与"相机无关的固定成形"都在这**，见下面「契约」 |
| 路径 | `paths.py` | 目的 → 目录 | 产出落点 | **所有效果图一律走这里，不许在别处拼路径** |
| 数据 | `stocks.py` | 卷名 → 参数 | **胶片卷表** | 换卷只改数据不改代码，新卷加一行 |

一切可调参数只在 `config.py`。改核心文件前先 commit。

### 基准成色（不属于任何卷）vs 卷

颜色分两层，职责别混：

* **基准成色**（`config.BASE_TABLE`）= **我方中性路径相对"大师平均"的系统性差**。
  四档：`BASE_NONE`（什么都不做，只留作 A/B 对照）/ `BASE_FOG`（只加雾）/ `BASE_DEYELLOW`（退黄+加雾）/
  `BASE_FULL`（全对齐：退黄 + 彩度微调 + 反差微调）。`cli bases` 能列出来。
  **默认 = `BASE_FULL`（09-13 SV 拍板）**；`config.BASE` 改这一行即可换默认，命令行 `--base` 可逐次覆盖。
  ⚠ `BASE_FULL` 的数**不是手写的**：09-13 入口补基线曝光之后，
  老那组手写数（照老基线解的）会"补两遍"，所以用 `_debug/calib_base_from_masters.py`
  **按当前基线重解了一遍**（目标 = 大师 1170 张整体中位）。改基线就得重跑它。
* **卷**（`stocks.py`）= **这条作者线相对"大师平均"的性格偏移**。

组装顺序 `cfg 默认 → 基准 → 卷`：偏移类（a/b/b_sh/b_hi）**相加**，彩度与对比**相乘**。
基准负责把我们的中性路径挪到"大师平均"上，卷再往作者线上偏 —— 换基准不会废掉卷。


### ★ 契约：三条负责什么（09-13 晚按「乙」重写；P0-1 结案）

> 旧文字「**曝光零点归入口、曲线形状归风格层**」**已作废** —— 入口自己也有一条形状曲线，
> 旧文字与实现打架（评审 P0-1）。现行契约：

1. **曝光零点归入口** —— 一个 EV 数（`×2^mid_ev`），只补"相机故意欠曝"那几档。
2. **相机无关的固定基准成形归入口** —— `y^ENTRY_GAMMA × ENTRY_LEVEL` + 软肩部。
   它**不含任何逐图/逐机型旋钮**（全局只有 4 个数）⇒ 它是"基准"，不是"风格"。
3. **胶片的影调性格归 L2 影调曲线** —— 全局给默认（`TONE_TOE/LIFT/SHOULDER`），卷可整组覆盖。

**为什么这么切**：外面三家都是"**一条曲线**"——
darktable spektrafilm 文档「never use spektrafilm together with another display transform」；
AgX「只用一种 display transform」；Adobe = `BaselineExposure`(一个 EV) + DCP `ToneCurve`(形状)，
形状也只有一条。我们这两条**分工不同、不重复**（入口那条全机型同一组常数，L2 那条才是性格）
⇒ 不再算"两个 display transform 串联"。

### 入口：零点 + 固定成形（Q1，09-13）

相机厂商**故意让 RAW 欠曝**，把"把中点抬回来"留给转换器（DNG 里叫 `BaselineExposure`）。

**零点**从 `cameras.ENTRY_CURVE` 取 —— 逐 **机型 × DR 档** 一组，从**真实 RAW + 机内 JPEG 同名对**
量出来（`_debug/calib_entry_curve_from_pairs.py`，**逐像素配对**、不是分位匹配）。
表里每组有两个字段，**用途完全不同**：

| 字段 | 是什么 | 谁在用 |
|---|---|---|
| `mid_ev` | Y=0.18 处的增益（**零点**，一个 EV 数） | **默认路径只用它**（`cameras.entry_zero_ev()`） |
| `anchors` | 增益-亮度曲线（**形状**） | ⚠ **默认路径下是死数据**，只有 `ENTRY_TONE=False` 时才被 `io.apply_entry_curve` 使用 |

> ★ **P1-6**：入口成形「乙」落地后，默认路径**只取零点**。之前本文档把 anchors 描述成"在用"，
> 属文档失真，已改。要零点请用 `cameras.entry_zero_ev()`，别去拆 anchors。

**已知数据缺陷（P1-6 顺带，09-13 晚）**：X-T30 III 的 DR 步进不自洽 ——
实测 DR100 **0.108** / DR200 **1.947** / DR400 **2.184** ⇒ 步进 **+1.84 / +0.24**，
而物理上该是 **+1 / +1**。两端各自反推 darktable 表（0.72/1.72/2.72）得到**同一个统一偏移 ≈ −0.57EV**，
**唯独 DR200 例外** ⇒ **DR200 那一组标定可疑**，库里 **66 张 DR200 会被多提约 0.8 档**。
⚠ 不能靠推导改（DR200 的 `mid_ev` 与自己的 anchors 是自洽的；整组比例缩放又会破坏"白端增益=1.0"）
⇒ **必须重标**。缺陷用 `cameras.FUJI_DR_STEP_KNOWN_BAD` 显式登记，`selftest` 守着它（重标后会提醒删掉）。

其它：`ENTRY_BIAS_ENABLE=False` 时**整件事一起跳过**（零点 + 曲线），A/B 对照组才是真的"没补过"；
读元数据（DR tag）**不受开关管** —— 开关管的是"补不补"，不是"读不读"。

### 颜色层是"目标域拟合"不是"物理密度模型"（P1-5，路线选择，显式记录）

GitHub 那批胶片模拟（spektrafilm / vkdt filmsim / Emulsifier / LIMO）**全是物理模型**：
光谱感光度 → 三层 H&D（logE→密度）→ 显影 → 印片 → 扫描，参数是 `d_min`/`d_max`/三通道穿透率/密度曲线 CSV。

我们**不是**：L2 是 `a*/b* 偏移 + 彩度 gamma(p,s) + 明度 S 曲线`，参数由**量大师的尺子反解**得到。

* **换来什么**：参数少、每个旋钮都能翻译成人话、换卷只改数据、可迭代（三条不可退让之一）。
* **代价**：表达不了**跨通道耦合** —— 比如"高光里 R 通道先滚降""层间化学交调（couplers）"，
  只能用 `HILIGHT_DESAT`（全局去饱和）和 `CHROMA_ENDS`（两端掉彩）打近似。
* **未来接口**：`config.FILM_MATRIX` 已留（线性域 3×3，默认恒等），但**没接密度曲线**。
  要上真 H&D，从它接。


### L1 过亮护栏 + 空间/颜色三处修正（v0.3.1，09-13）

**① L1 过亮护栏改「折中」**（`GUARD_MID = 0.854`）。
原来护栏线 = `TGT_MID`（灰阶 140），而 140 是**大师全体逐图「中位 L*」的中位数** ——
拿组内中位当**逐图**上限，等于把正常亮片压闷（入口已经把中位送到贴住相机 161，L1 又把它拽回 138）。

实测大师 1172 张逐图「中位 L*」：P50=58.0 / P90=82.7 / **P95=87.0** / P99=94.1 / max=99.7
（`_debug/analysis/master_resurvey.json`）⇒ 取 **P95**：只有比 95% 的大师成片还亮才算"亮得离谱"，
**压回的落点也是这条线**（灰阶 218），不是拽到 140。

**② 颗粒高光精确归零**：原来写成"高光只压 70%"⇒ 白墙/天空还留 30% 颗粒在动。
物理上密度饱和区没有可显影的银盐，外面（LIMO / Emulsifier）**两端都精确为 0**。
现在 `GRAIN_HI_LO=0.86 / GRAIN_HI_HI=0.98`，g≥0.98 精确为 0。

**③ Halation 分通道半径**（`HALATION_RADIUS_RATIOS = [1.0, 0.45, 0.15]`）：
红光穿透片基散射得最远、蓝光几乎不散（LIMO `RED/GREEN/BLUE_PENETRATION = 0.88/0.10/0.02`，
spektrafilm 也是三通道各自独立的散射 sigma）⇒ 红边变成"外圈红、里层白"，不再是把亮部整块叠一层橙。
⚠ **总能量比以前低**（G/B 扩散得少），真实成片上的强度可能要重新试。

**④ 抽色饱和（两端掉彩）** `CHROMA_ENDS = 0.20`：
`sat_mult = 1 - subsat*(2*L/100-1)^2`（出处 Emulsifier `engine.py`）——
中间调 L*=50 不动、两端掉彩。L1 的 `HILIGHT_DESAT` 只管高光端，这里补上**暗部端**。
⚠ 它改了彩度形状 ⇒ **`BASE_FULL` 必须重解**（chroma_p 0.866→0.913、chroma_s 1.037→0.959）。

> 调研出处：`E:\WorkBuddy\摄影助手\调研_数码仿胶片实现_对svFilm的启发_0913.md`，
> 源码实证在 `_debug/_rs/`（LIMO 的 Metal + Emulsifier 的 engine.py/真 H&D 曲线）。
> 对照图：`园岭新村\效果debug\2026-09-13\v031_四处改动AB\`（A 整图三栏 / B 最亮处裁切 / C2 Halation 示意 / D 颗粒包络）。


### L3 肤色：保护 + 正向达标（09-13 SV 拍板「全」档）

为什么：L3 原来只做「保护」（把风格层收掉的色度还回来），**没有往目标靠的动作**。
而 `BASE_FULL` 的「退黄」是**按整图中位**解的，**脸比整图更暖** ⇒ 全局退黄把脸一起退冷。
实测（`_debug/analysis/skin_master_ruler.md`，33 位作者，**用 svFilm 自己的面膜**量）：

| | a* | b* |
|---|---|---|
| 大师脸区 P50 | **16.3** | **18.5** |
| **机内 JPEG 的脸** | **15.3** | **17.9** |
| 我们成片（改前） | 12.2 | 12.4 |

⇒ **不是缺血色，是缺暖**。规则（`config.SKIN_FLOOR_*`）：

* **逐像素达标**：每个皮肤像素自己看"离目标还差多少"，差多少补多少（单像素位移设上限
  a* 8.0 / b* 12.0，护唇妆/腮红这种本来就浓的不会被推爆）；**只向上补**，已在目标之上就一分不动。
* **只改色度不改明度**（与 L3 契约一致）。
* **两轴都低才补**：某个轴已经超过目标 `SKIN_FLOOR_EXCESS`（4.0）就完全不补 —— 挡住
  "一轴已经很高"的彩色物体被顺手推暖（典型：粉衣服、木色背景）。
* **过亮门（逐像素）**：皮肤像素 L* ≤ 73.3（大师脸区 P90）全强度、≥ 83.7 不补 ——
  逆光/高调脸的高光部分自己不补，**暗部照样补**，而不是整张脸一刀切。
* 关掉：`SKIN_FLOOR = False`（单测 `_Cfg` 默认关，与 `BASE_NONE`/`CHROMA_ENDS=0` 同理）。

> ★ **设计教训（本条的由来，别再犯）**：最初用「**全图**肤色的中位算一个位移、再作用到所有皮肤像素」——
> 这是**整体统计量当局部目标**，和早就踩过的「组内中位数不能当逐图上限」是同一类错误。
> 后果：掩膜会把粉衣服/木色/路面算进来（实测园岭某张 **15.3%** 的像素被判成皮肤），
> 中位被彩色物体拉低 ⇒ **人脸被推过头**（实测 b* 冲到 20.4，目标 18.5）；过亮门也据此判错。
> **改成逐像素**之后，人脸精确落在目标上、彩色物体自己不动。**凡是"一个数代表一整类像素"的地方都要先问：
> 这个统计量是不是被不属于这类的像素污染了。**

验证：`_debug/lab_skin_floor_verify.py`（**跑生产链**，只切这一个开关，出改前/改后/机内JPEG 三栏图）。

### 卷（甲）与空间域（乙丙丁）

一个"卷"就是一份数据，两半：

* **颜色**（L2 用）：a\*/b\* 偏移、暗部·亮部 b\* 分离、彩度(p, s)、明度对比
* **空间**（`spatial.py` 用）：颗粒 / 黑柔 / Halation 的强度

现有 7 卷：`neutral`（什么都不做的基准）、`portra400`、`pro400h`、`fuji_c200`、`ektar100`、
`cinestill800t`（带 Halation）、`air`。

**数值是量出来的，不是手编的**（v0.2.1 起）：卷名/方向继承 09-10《胶片卷映射与分组策略》，
颜色数值由 `_debug/calib_stocks_from_masters.py` 从 **1170 张大师成片**（`master_resurvey.json`）量出。
口径 =「取神不取形」：**卷 = 这条作者线相对"大师全体中位"的性格偏移**。
逐卷证据 → `效果debug/<日期>/卷标定_大师颜色聚类/卷标定报告.md`。
只有 `pro400h` 没标定（数据里没有"青绿粉彩"那条线）→ `calibrated=False`，仍是手写。

为什么空间三件必须单独一层：`.cube` 是**逐像素查表**，只能装颜色和影调；
颗粒、黑柔（光学扩散）、Halation（片基红光散射）都是**看邻域**的运算，LUT 装不下。

svFilm/                    工程（git 仓库，只放产品代码）
  svFilm/                  包：L0~L4 + 空间域 + 入口 + 路径 + 卷表
  <样片目录>/效果debug/<日期 YYYY-MM-DD>/<目的说明>/<文件>

- 一级 `效果debug`：所有"给人看效果"的产物归到这里，不再散落在样片旁边。
- 二级日期默认今天，三级是这批图**为了看什么**（例：`三张RAW_分段对照`）。
- `cli dir` 扫描时**整棵跳过 `效果debug`**，避免把上一轮的产出当素材再处理一遍。
- 调试脚本**不在工程里**：它们写着样片/大师作品的绝对路径和作者名，进仓库等于泄露。
  在工程根执行时用 `../_debug/xxx.py`；脚本内部靠 `SVFILM_ROOT` 环境变量找工程根（默认 `../svFilm`）。
